# Cover letter rules (example for any person)

Copy this file to `cover_letter_instruction.md` in the same folder and edit it. Without that
file the app uses its built-in general rules. Words in double braces are filled in by the app:
`{{name}}`, `{{first_name}}`, `{{location}}`, `{{right_to_work}}`, `{{start}}`.
The last three come from Options, "About you"; leave them empty there and the letter will not
mention them.

## 1. Sell strengths only

The letter is written by {{first_name}} in the first person (I, my). It never mentions anything
{{first_name}} has not done: no "not yet", "although", "limited experience", "I lack". A
requirement that cannot be backed up is left out, turned into a forward-looking wish ("I would
like to bring the same drive to ..."), or answered with the nearest real evidence.

## 2. Format

The head, date, greeting, signature, fonts and page setup come from the letter template and are
never changed. Only the title line, the date and the body paragraphs get new text.

## 3. Honesty

Only technologies that are in the master CV may appear as experience.

## 4. Structure

Five paragraphs, about 330 to 400 words in total:
1. Hook: the role, the company, why this work attracts.
2. Strongest evidence for the main requirement: one real project with concrete facts.
3. A second theme from the posting, with one short true story or result.
4. Learning and fit, then the forward-looking wish.
5. Close: based in {{location}}; right to work: {{right_to_work}}; can start: {{start}}; an
   invitation to talk. A fact marked "(not stated)" is left out.

## 5. Writing rules

Open sentences with different subjects, one concrete number or fact per paragraph, no filler
openers ("I am passionate", "I strongly believe"), no restating the CV line by line, no hedging.
Use an en dash with spaces, never an em dash. No emojis.

## 7. Example opening

"The Junior Data Analyst role in your reporting team caught my attention because it puts SQL and
clear communication at the centre of daily work, which is how I already like to work."
